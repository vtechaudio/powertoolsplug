# PowerPlug Pro Child Theme

Activate this child theme (Appearance -> Themes) and put ALL customizations here so parent updates never overwrite your work.

- `style.css` - your custom CSS (loaded after the parent).
- `functions.php` - enqueues the parent stylesheet and shows an example `powerplug_business_details` filter.

Parent theme required: **PowerPlug Pro 2.10.0+**.
